# vice-cover-studio

Turn your photo into a multi-panel GTA-style poster cover. Spread one photo across tilted panels or give each panel its own shot, frame every panel independently with per-panel zoom and pan sliders, and add an editable caption in heavy poster lettering across the lower third. Choose from Sunset, Neon night and Golden hour colour grades and from Classic hero, Duo and Grid layouts, then export in one click as a PNG at 1080x1080, 1080x1350 or 1920x1080. Three built-in sample scenes — Boulevard, Pier and Harbor — were rendered in 3D for this project, so you can try the studio straight away. Photos are processed locally in the browser only and are never uploaded. All artwork, lettering and scenes are original. The caption typeface is Anton, used under the SIL Open Font License 1.1 — see app/fonts/OFL.txt.

## Run it

```
node serve.ts
```

Then open http://localhost:8080 in a desktop browser — no build step, no network needed, app/ is fully static and offline-capable.

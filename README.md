Vice Cover Studio is a GTA-poster-style cover art maker that runs entirely in your browser: drop in your own photos, arrange them across angled poster panels, add bold caption lettering and a sunset or neon grade, and export a share-ready PNG in 1080x1080, 1080x1350 or 1920x1080. It ships with three built-in 3D-rendered sample scenes (a sunset boulevard, a neon pier and a golden-hour harbour) so you can make a cover before loading any photo of your own. Photos never leave your machine.

## Run it

```sh
node serve.ts
```
then open http://localhost:8080

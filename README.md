Vice Cover Studio turns your own photo into a multi-panel GTA-style poster cover. Drop in a photo and spread it across several tilted panels, or give every panel its own shot, then frame each panel independently with per-panel zoom and pan sliders so every crop is exactly where you want it. Edit the caption, finish with heavy poster lettering across the lower third and a sunset, neon or gold colour grade, and pick from three layouts — Classic hero, Duo and Grid. Export your finished cover in one click as a PNG at 1080x1080, 1080x1350 or 1920x1080. Three built-in sample scenes — Boulevard, Pier and Harbor — are rendered in 3D for this project so you can try the studio straight away. Photos are processed locally in the browser only and nothing is ever uploaded. All artwork, lettering and scenes are original, and the caption typeface is Anton under the SIL Open Font License 1.1 (see app/fonts/OFL.txt).

## Run it

```
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. There is no build step and no network needed — the app/ directory is fully static and offline-capable.
